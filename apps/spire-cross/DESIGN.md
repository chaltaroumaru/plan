# スパイア・クロス 仕様書 (v2 / パーティバトル版)

> 本ドキュメントは、初期プロトタイプ(単一HPプール・ローグライク探索)から仕様変更する
> 「パーティバトル+スキルツリー+ダンジョン/ストーリー」版の設計をまとめたものです。
> 実装は本ドキュメントの内容に合わせて既存コードを改修していきます。

## 1. コンセプト・世界観

- タイトル: **スパイア・クロス**
- 通貨(ガチャ用ストーン): **交界石(こうかいせき)** — 世界の境界が交わる場所で生まれる神秘の石
- 世界観: 無数の世界の境界(クロス)が交わる場所に聳える塔(スパイア)を巡る物語。
  **「めちゃくちゃきれいで神秘的」**なビジュアルトーン。キャラクターデザインも美麗・可憐路線。
- ジャンル: スレイ・ザ・スパイア風のカードバトル × グランドクロス風のキャラ収集・育成ソシャゲ

## 3. キャラクター

- 既存の13体(N×4 / R×4 / SR×3 / SSR×2)を土台として流用し、新仕様に対応させる。
- 各キャラは **個別HP** を持つ(旧仕様の単一HPプールは廃止)。
- 基礎ステータス: HP / 攻撃力 / 防御力(+ スキルツリーで伸ばせる派生ステータスは4章参照)

## 4. スキルツリー

各キャラごとに専用のスキルツリーを持つ。

### 4.1 スキルツリーポイント

- レベルアップで獲得。
- 1pt消費: 基礎ステータス強化ノード
  - HP / 攻撃力 / 防御力
  - クリティカル率 / ダメージカット率
  - 必殺技ゲージのターン短縮
- 消費pt増 + 条件達成: 特殊効果ノード・必殺技解放ノード

### 4.2 覚醒スキル

- 解放条件: ダンジョンで専用素材を集める + 必要キャラレベルに到達
- 効果: 特殊効果や新たな必殺技演出など、キャラの上限を引き上げる要素

### 4.3 必殺技(必殺技ゲージ)

- 手札のカードとは**別枠**の仕組み。
- パズル&ドラゴンズのスキルターン制を採用: 各キャラに「あと◯ターンで使用可能」のカウンターが付き、
  カウントが0になると使用可能になる単体対象の強力な技。
- スキルツリーの「必殺技ゲージターン短縮」ノードで、貯まるまでのターン数を短縮できる。

### 4.4 カード⇄スキルツリー連動

2つの仕組みを併用する:

1. **所持が解放条件になるノード**: スキルツリー内には特定のカードに対応した特殊ノードがあり、
   そのカードを1枚以上所持していないと当該ノードには振れない(カード収集がキャラ成長の鍵になる)。
2. **属性マッチボーナス**: カード・スキルツリーノードの双方に属性(火/水/光/闇など)を持たせ、
   使用カードの属性とスキルツリーで伸ばしたノードの属性が一致すると効果がアップする。
   属性一致は必須ではないが、組み合わせ次第でキャラが強くなる。

## 5. カード

- 現状は **通常カードのみ**(スキルカードという別枠は無し。将来的に装備枠を追加予定)。
- カードは**パーティ共有の手札**に入る。どのカードも、バトル中に選んだキャラで使用できる
  (カードがキャラ専属ではない)。
- 山札の運用はスレイ・ザ・スパイア式:
  - 事前に組んだ固定デッキ(山札)からスタート
  - 毎ターン5枚ドロー
  - 山札が0枚になった状態でターンを終了すると、捨札をすべて山札に戻してシャッフルし、
    次ターンまた5枚ドローする

## 6. バトルシステム

### 6.1 パーティ編成

- 1パーティ = キャラ3体
- 編成画面でキャラとデッキ(カード構成)を設定してから出撃する

### 6.2 バトルの流れ

1. パーティ編成(キャラ・デッキ設定)
2. バトル開始
3. カードを手札に配置(5枚ドロー)
4. カードを選択 → 使用するキャラを選択 → 対象を選択して発動
   - 対象選択は**単体選択のみ**でまず実装(全体・ランダム複数対象は将来拡張)
5. 各キャラ・各敵が個別HPを持ち、**味方全滅 or 敵全滅**でバトル終了
6. 敵は1体〜複数体で構成される
7. ターン進行は**ラウンド制**(味方全員が行動 → 敵全員が行動、を繰り返す)

## 7. ガチャ

- ガチャは **キャラガチャ** と **カードガチャ** の2種類(将来的に装備ガチャを追加予定)
- 通貨: 交界石

## 8. ダンジョン

- **AP(スタミナ)制**を採用。時間経過で回復するAPを消費して挑戦する。
- ステージカテゴリ:
  - 強化素材クエスト
  - 進化素材クエスト
  - スキルツリー特殊解放素材クエスト
  - 降臨(期間限定の強力ボス)
  - イベントバトル
- 旧仕様の「ノードマップ探索(ローグライク)」は本仕様のダンジョンには含まれない
  (役割が異なるため、既存のマップ機能は撤去 or 別要素として整理する)

## 9. ストーリー

- ダンジョンとは別進行のメインシナリオ
- 章立てのステージクリア型
- 規模: **短編プロトタイプ(1章・数ステージ)** からスタート

## 10. 現行プロトタイプからの主な変更点まとめ

| 項目 | 旧仕様(初期プロトタイプ) | 新仕様 |
|---|---|---|
| HP | プレイヤー単一HPプール | キャラ個別HP、敵も個別HP |
| デッキ | キャラ専属カードのみでデッキ構築 | パーティ共有デッキ、誰でも使用可 |
| カード使用 | カードをプレイするだけ | カード→使用キャラ→対象、の3ステップ |
| キャラ成長 | 無し(ガチャで固定ステータス) | レベル+スキルツリーで個別育成 |
| 必殺技 | 無し | パズドラ式スキルターンで発動 |
| 探索 | ローグライクなノードマップ | ダンジョン(AP制のステージ選択)+ストーリー(章立て) |
| ガチャ | キャラのみ | キャラ/カードの2種 |
| 通貨 | ジェム | 交界石 |
