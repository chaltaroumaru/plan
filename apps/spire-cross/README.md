# スパイア・クロス (spire-cross)

「スレイ・ザ・スパイア」風のデッキ構築ローグライク戦闘と、「グランドクロス」風のキャラクターガチャ収集を組み合わせた、1人用のソーシャルゲーム風プロトタイプです。React Native (Expo) + TypeScript で実装しており、データはすべて端末内 (AsyncStorage) に保存されます。サーバーやアカウント登録は不要です。

## 遊び方

1. **ホーム** タブで所持キャラクターから最大3体のパーティを編成し、「冒険を始める」で新しいランを開始します。
2. **ガチャ** タブでジェムを消費してキャラクターを引きます (単発/10連、天井あり)。引いたキャラクターの専用カードが、そのキャラクターをパーティに入れたときにデッキへ追加されます。
3. **冒険** タブでノードマップを進みます。戦闘・エリート・休憩・ショップ・イベント・ボスの各ノードがあります。
4. 戦闘はターン制のカードバトルです。エネルギーを消費してカードをプレイし、敵の「次の行動」を見ながらブロックや攻撃を選択します。
5. 戦闘に勝利するとゴールドと(エリート/ボスは)ジェム、そしてデッキに加えるカードを1枚選べます。
6. **コレクション** タブで所持キャラクターの一覧と専用カードを確認できます。

## 開発

```bash
npm install
npm run web    # ブラウザで起動 (react-dom / react-native-web が必要)
npm run start  # Expo Dev Tools (実機は Expo Go アプリでQRコードを読み取り)
```

型チェック: `npx tsc --noEmit`

## 主なディレクトリ

- `src/types` : 型定義
- `src/data` : キャラクター・カード・敵のマスタデータ
- `src/game` : ガチャ抽選・マップ生成・バトルロジック
- `src/storage` : AsyncStorage 永続化
- `src/state` : アプリ全体のゲーム状態 (React Context)
- `src/screens` : 各画面 (ホーム/ガチャ/コレクション/冒険)
- `src/components` : 共通UIコンポーネント
