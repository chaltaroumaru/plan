# スパイア・クロス (spire-cross)

「スレイ・ザ・スパイア」風のカードバトルと、「グランドクロス」風のキャラクター収集・育成(スキルツリー)を組み合わせた、1人用のソーシャルゲーム風プロトタイプです。React Native (Expo) + TypeScript で実装しており、データはすべて端末内 (AsyncStorage) に保存されます。サーバーやアカウント登録は不要です。

詳しい仕様は [`DESIGN.md`](DESIGN.md) を参照してください。

## 遊び方

1. **キャラ** タブでパーティ編成(最大3体)とデッキ編成(10〜20枚、パーティ全員が共有して使用)を行います。
2. **ガチャ** タブで交界石を消費してキャラ/カードを引きます(それぞれ別プール、単発/10連、天井あり)。
3. **ストーリー** タブで章立てのステージを順番に攻略します。**ダンジョン** タブではAP(スタミナ)を消費して、強化・進化・スキルツリー解放素材の収集や降臨・イベントに挑戦できます。
4. バトルはラウンド制のカードバトルです。カードを選ぶ→使用するキャラを選ぶ→対象(敵)を選ぶ、の3ステップで行動します。キャラは個別にHPを持ち、味方全滅または敵全滅で終了します。
5. **キャラ** タブの各キャラ詳細から、レベルアップで得たスキルポイントをスキルツリーに振り、基礎ステータス強化や必殺技解放ができます。一部のノードは専用カードの所持や素材が解放条件になります。
6. 必殺技はカードとは別枠で、ラウンドを経るごとにゲージ(クールダウン)が進み、貯まると発動できます。

## 開発

```bash
npm install
npm run web    # ブラウザで起動 (react-dom / react-native-web が必要)
npm run start  # Expo Dev Tools (実機は Expo Go アプリでQRコードを読み取り)
```

型チェック: `npx tsc --noEmit`

## 主なディレクトリ

- `src/types` : 型定義
- `src/data` : キャラクター・カード・敵・スキルツリー・ダンジョン/ストーリーステージのマスタデータ
- `src/game` : ガチャ抽選・バトルロジック・スキルツリー計算・レベリング・AP回復・デッキ検証
- `src/storage` : AsyncStorage 永続化
- `src/state` : アプリ全体のゲーム状態 (React Context)
- `src/screens` : 各画面 (ホーム/ダンジョン/ストーリー/キャラ/ガチャ/設定、キャラ詳細・パーティ編成・デッキ編成・バトル)
- `src/components` : 共通UIコンポーネント
