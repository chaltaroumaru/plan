# スパイア・クロス ChatGPT画像生成プロンプト集

> `STORY.md` の世界観(境界が交わる場所に聳える神秘的な塔・交界石=想いの結晶・記憶のかけら)と、
> 6章の13体分の個別キャラクタープロフィール(元ネタ・性格・外見の方向性)に合わせた、
> ChatGPT(画像生成)に貼り付けて使うプロンプトのテンプレート集です。
> `{ }` で囲んだ部分を差し替えるだけで、キャラやカードが増えても同じ画風で量産できます。
>
> **方向性(v3)**: 神秘的な世界観の軸は保ちつつ、「旅人が記憶を失っている」という
> ストーリー上の背景を反映し、全体的なトーンを少し暗く・翳りのあるものにする。
> さらに塔そのものを「近未来都市」と一体化した存在として描き、超古代/超未来の
> クリスタル・テクノロジーが息づく大都市——という新しい方向性を主軸に据える。

## 0. 共通スタイルアンカー(全プロンプトの先頭に必ず付ける)

キャラ・カード・背景すべてに共通で入れる「世界観の軸」。これを毎回コピペすることで、
生成のたびに絵柄がブレるのを防ぐ。

```
世界観: 無数の世界の境界(バウンダリー)が交わる場所に聳える、神秘的な塔「スパイア」を舞台にした
ファンタジーRPG。塔は消えていった世界の想いを結晶化して保存する、超古代にして超未来的な装置で
あり、その足元には塔と融合するように発展した近未来都市が広がっている。
テイスト: 「神秘的」×「近未来都市」×「翳りのある静けさ」のハイブリッド。主人公が大切な記憶を
失っているという物語の背景を反映し、全体的な色調は明るい黄金色よりも、夜明け前や夕闇のような
少し暗く、霧がかった、物憂げなトーンを基調にする。紺碧・深紫・墨色を土台に、結晶の発光ラインと
都市のネオン・光の粒子だけが、闇の中に静かに浮かび上がるような光と影のコントラストを意識する。
結晶の内部には幾何学的な光の回路(サーキット状の発光ライン)が走り、ホログラムのように半透明で
浮かぶ記号・紋様(ルーン)が漂う。表面は磨かれたクリスタル・ガラス・淡く発光する金属が融合した
質感。透明感のある光の演出、繊細な線、美麗で可憐なアニメ/ソシャゲ風イラスト。
```

## 1. ホーム背景(拠点全景・複数ホットスポット)

ホーム画面を「キャラ(宿)・ショップ(屋台)・ダンジョン(塔)・ガチャ(魔法陣)が
すべて見える1枚の拠点イラスト」に刷新するための背景。各要素をタップ可能な
UIホットスポットにする前提のため、4つの場所が視覚的にはっきり分離して見える
構図にする。

```
{共通スタイルアンカー}

ゲームのホーム画面用に、拠点全体を見渡せる1枚のイラストを生成してください。
画面内に、以下4つの場所が同時にすべて見える構図にしてください(のちにそれぞれを
タップ可能なUIホットスポットにするため、各場所が視覚的にはっきり分離して
見えるようにしてください)。

1. 宿(キャラクター編成の場所): 温かい灯りが漏れる、木造とクリスタルが融合した
   小さな宿屋の建物。画面の左下寄りに配置。
2. 屋台(ショップ、新規追加): 幌のかかった露店。クリスタル製のランプや道具が
   並んでいる。画面の右下寄りに配置。
3. 塔(ダンジョン): 画面奥・中央〜上部にそびえる、白銀と紺碧の結晶の塔。
   遠景として大きく配置し、他の建物より高くそびえて見えるようにする。
4. 魔法陣(ガチャ): 地面に描かれた、淡く発光する円形の魔法陣。周囲に浮遊する
   結晶の欠片が舞う。画面中央やや手前に配置。

構図: 見下ろすような俯瞰(アイソメトリック風)の構図で、4つの場所が一枚の
広場・集落として自然に繋がって見えるようにする。
時間帯・雰囲気: 夕闇〜夜明け前の薄暗い時間帯。宿の窓明かり、屋台のランプ、
塔の結晶の発光、魔法陣の光——それぞれの光源が暗がりの中に浮かび上がるようにする。
縦横比: 9:16(スマホ画面比率)。UIを重ねる前提で、画面下部1/4程度は
自然に暗く沈み込むグラデーションにする。
キャラクターは配置しない(背景のみ)。
```

重ねる前提。

奥に暖炉やランプの明かり、壁には旅の記録を思わせる地図や紋章が飾られている。
画面中央〜上部は、パーティメンバー(最大3体)の立ち絵とそれを囲む枠UIを
重ねる前提で、奥行きのある空間として描く。
画面下部は、メニューUIを重ねる前提で、家具や床のディテールを落ち着いたトーンで
描き、コントラストを抑える。
縦横比: 9:16。時間帯: 夜、暖色の室内灯が中心。ホーム画面より暖かみのある配色に
振ってよい(宿=安らぎの場所であることを表現する)。
```

```

## 6. キャラクターデザイン テンプレ

STORY.md 6章の元ネタは日本神話・妖怪とギリシャ神話が混在している(5.0節の通り、
塔が無数の世界の境界が交わる場所である以上、複数の神話が共存するのは必然という設定)。
どちらの系統でも、共通スタイルアンカーの「神秘的×近未来都市」トーンは変えない。

`STORY.md` 6章の個別プロフィール(元ネタ・性格・外見の方向性)と
`src/data/characters.ts` のデータ(名前・二つ名・属性・レアリティ)を組み合わせて使う
プロンプト。立ち絵(全身)とアイコン(バストアップ)の2種類のテンプレを用意。
**キャラクターデザインを作る前に、必ずSTORY.md 6章でそのキャラの元ネタ・性格・
外見の方向性を確認してから埋めること。**

```

属性: {element}属性 → 属性に応じた色・モチーフを衣装や武器に反映させる
  (火=赤〜橙, 水=青〜水色, 風=緑, 土=茶〜黄土色, 雷=黄〜金, 光=白〜金, 闇=紫〜黒)
レアリティ: {rarity}(N/R/SR/SSRの順で装飾・オーラの派手さを段階的に強くする。
  N/Rは実用的で簡素な意匠、SR/SSRは装飾が増え、光の粒子やオーラ演出を加える)
元ネタモチーフ: {STORY.mdの「元ネタ」。例: 雪女(旅人を凍らせるが、情を通わせた相手だけは
  見逃したという伝承)} → シルエットや小物、色使いにさりげなく反映させる
  (直接的なコスプレにはせず、「言われてみれば元ネタが分かる」程度の抽象度に留める)

  冷気をまとう長い黒髪}

淡い発光エフェクトを加える。背景は近未来都市のシルエットをうっすら透過で
匂わせる程度に留め、主役はあくまでキャラクター本体にする。

## 7. カードデザイン テンプレ

`src/data/cards.ts` の1枚分のデータ(カード名・種別・属性・関連キャラ)を
差し込んで使うプロンプト。カード全体のフレーム込みで生成する。
**レアリティが上がるほど、絵の情報量・光の演出・フレームの豪華さを明確に段階的に
上げること**(N→R→SR→SSRで一段ずつ格が上がって見えるようにする)。

### 4.1 レアリティ別クオリティ指針(必ずプロンプトに含める)

| レアリティ | 構図 | エフェクト | フレーム |
|---|---|---|---|
| N | 静止した簡潔な構図、被写体1つ | エフェクトはほぼ無し、最小限の光沢のみ | シンプルな線のみの縁取り |
| R | ややダイナミックな構図 | 属性カラーの淡いグロー・小さな光の粒子 | 縁取りに細い発光回路ラインを追加 |
| SR | 動きのある構図、背景に簡単なエフェクト | 属性カラーの強いグロー、飛び散る光の粒子、箔押しのような光沢 | 縁取りが二重になり装飾紋様が増える |
| SSR | フルダイナミックな構図、背景まで作り込む | 画面全体を包む光のオーラ、虹色/ホログラム的な反射、粒子エフェクトが最も豊か | 縁取りが最も装飾的、四隅に紋章、後光のような光背 |

### 4.2 プロンプト本体

```
{共通スタイルアンカー}

トレーディングカード風のイラストを1枚生成してください。カード全体のフレームも含めて描く。
カード名: {name}
カード種別: {type}(attack=攻撃/skill=スキル/power=パワー)
  → attackは攻撃的な一瞬の動作、skillは技や防御の構え、powerは持続効果を示す
    象徴的なオーラ/紋章のイラストにする
属性: {element}(属性ごとの色をカード全体の縁取り・背景エフェクトに反映)

## 9. 運用メモ

- 同じキャラ/カードで生成し直す場合は、上記プロンプトに加えて
  「前回生成した{キャラ名}と同じ配色・デザインの方向性で」を末尾に足すと再現性が上がる。
- SSRクラスは装飾過多になりがちなので、生成後に「もう少しシンプルに」と
  追加指示を出すと調整しやすい。
- 「近未来的」要素(発光回路・ホログラム紋様)が強すぎてSFになりすぎた場合は、
  「回路のラインをもっと有機的で植物のツルのような曲線にして、機械的な直線を減らして」
  と指示すると、神秘寄りに調整しやすい。
- 元ネタモチーフを反映させすぎて特定の実在キャラクター(既存作品のコスプレ)に
  寄りすぎた場合は、「元ネタが分かる程度に抽象化して、もっとオリジナルのシルエットに」
  と指示すると調整しやすい。
- 生成した画像は `assets/backgrounds/`(背景)・`assets/characters/`・`assets/cards/`・
  `assets/materials/`(いずれも今後追加予定)に配置し、PNG→JPEG圧縮(背景)や
  透過PNGのまま(キャラ/カード/アイコン)でバンドルサイズを抑えて取り込む。
