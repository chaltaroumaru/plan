# スパイア・クロス ChatGPT画像生成プロンプト集

> `STORY.md` の世界観(境界が交わる場所に聳える神秘的な塔・交界石=想いの結晶・記憶のかけら)と、
> 6章の13体分の個別キャラクタープロフィール(元ネタ・性格・外見の方向性)に合わせた、
> ChatGPT(画像生成)に貼り付けて使うプロンプトのテンプレート集です。
> `{ }` で囲んだ部分を差し替えるだけで、キャラやカードが増えても同じ画風で量産できます。
>
> **方向性(v3)**: 神秘的な世界観の軸は保ちつつ、「旅人が記憶を失っている」という
> ストーリー上の背景を反映し、全体的なトーンを少し暗く・翳りのあるものにする。
> さらに塔そのものを「近未来都市」と一体化した存在として描き、超古代/超未来の
> クリスタル・テクノロジーが息づく大都市——という新しい方向性を主軸に据える。

## 0. 共通スタイルアンカー(全プロンプトの先頭に必ず付ける)

キャラ・カード・背景すべてに共通で入れる「世界観の軸」。これを毎回コピペすることで、
生成のたびに絵柄がブレるのを防ぐ。

```
世界観: 無数の世界の境界(バウンダリー)が交わる場所に聳える、神秘的な塔「スパイア」を舞台にした
ファンタジーRPG。塔は消えていった世界の想いを結晶化して保存する、超古代にして超未来的な装置で
あり、その足元には塔と融合するように発展した近未来都市が広がっている。
テイスト: 「神秘的」×「近未来都市」×「翳りのある静けさ」のハイブリッド。主人公が大切な記憶を
失っているという物語の背景を反映し、全体的な色調は明るい黄金色よりも、夜明け前や夕闇のような
少し暗く、霧がかった、物憂げなトーンを基調にする。紺碧・深紫・墨色を土台に、結晶の発光ラインと
都市のネオン・光の粒子だけが、闇の中に静かに浮かび上がるような光と影のコントラストを意識する。
結晶の内部には幾何学的な光の回路(サーキット状の発光ライン)が走り、ホログラムのように半透明で
浮かぶ記号・紋様(ルーン)が漂う。表面は磨かれたクリスタル・ガラス・淡く発光する金属が融合した
質感。透明感のある光の演出、繊細な線、美麗で可憐なアニメ/ソシャゲ風イラスト。
```

## 1. ホーム背景(拠点/ホーム画面用)

すでに実装済みの背景画像(`assets/backgrounds/home_background.jpg`)を、
「神秘的だが記憶喪失というストーリー背景を踏まえた、翳りのある近未来都市」路線に
更新したいときに使う。

```
{共通スタイルアンカー}

縦長のスマートフォン壁紙イラストを1枚生成してください。
構図: 画面中央〜上部に、天まで届く巨大な塔「スパイア」を下から見上げるように配置。
塔の中腹から下は、塔と融合するように積み重なった近未来都市——結晶とガラス質の
高層建築群、宙に浮かぶ通路、淡く発光する道の光跡——が広がっている。
都市の窓明かりやネオンは、暖かい賑やかさではなく、記憶の断片のようにぽつぽつと
まばらに灯る寂しさを感じさせるトーンにする。
塔と都市の外壁には結晶と、幾何学的に走る発光ラインの回路が組み合わさっており、
所々に半透明のホログラム状の光の紋様(記憶のかけらを思わせる、割れたガラスのような
淡い光の破片)が浮遊している。
画面下部は霧に沈む都市の底、または雲海を描き、UIを重ねても視認性が保てるよう
下部1/3ほどは自然に暗く沈み込むグラデーションにする。
キャラクターは配置しない(背景のみ、UIオーバーレイ前提)。
縦横比: 9:16(スマホ画面比率)。塔の構図は画面上端付近で揃うようにする。
時間帯・雰囲気: {例: 夜明け前の静けさと薄紫の霧 / 夕闇に沈む都市と最初の星明かり /
  雨上がりの夜、濡れた路面に反射する結晶の光}
```

## 2. バトルフィールド背景

バトル画面用。ホーム背景よりも横長・奥行きのある構図にし、UI(敵/味方/手札)を
重ねる前提で中央〜下部を比較的落ち着いた色味にする。

```
{共通スタイルアンカー}

バトル画面用の背景イラストを1枚生成してください。
構図: 塔の内部、または塔と一体化した近未来都市の一角(高架の通路・廃墟化した
結晶ビルの谷間・地下の記憶回廊など)。奥に塔本体や結晶の柱、都市の光跡が霞んで
見える構図。柱や床の一部に、起動中の発光回路や、薄く浮かぶホログラム状の記号列
(記憶の記録が可視化されたもののような演出)を配置する。
画面中央〜上部にはある程度の空間的な奥行きを残し、敵キャラクターの立ち絵を
重ねても違和感が出ないようにする。
画面下部1/3は、味方キャラクター・手札UIを重ねる前提で、コントラストを落とした
落ち着いた色味(暗めの紺・墨紫)にする。
縦横比: 9:16(スマホ画面比率)。
エリアの指定: {例: 塔の入り口付近・崩れかけた回廊 / 都市中層・廃墟化した
  結晶タワーの谷間 / 塔上層・雲を突き抜けた尖塔と都市の光を見下ろす足場}
明るさ: 主UIの視認性を優先し、全体的に彩度・明度をやや抑える。記憶喪失というテーマを
反映し、画面の端が薄い靄でぼやけているような、輪郭の曖昧さをわずかに加える。
```

## 3. キャラクターデザイン テンプレ

`STORY.md` 6章の個別プロフィール(元ネタ・性格・外見の方向性)と
`src/data/characters.ts` のデータ(名前・二つ名・属性・レアリティ)を組み合わせて使う
プロンプト。立ち絵(全身)とアイコン(バストアップ)の2種類のテンプレを用意。
**キャラクターデザインを作る前に、必ずSTORY.md 6章でそのキャラの元ネタ・性格・
外見の方向性を確認してから埋めること。**

### 3.1 全身立ち絵(テンプレ)

```
{共通スタイルアンカー}

キャラクターの全身立ち絵イラストを1枚生成してください。背景は透過(白背景でも可)。
キャラクター名: {name}
二つ名: {title}
属性: {element}属性 → 属性に応じた色・モチーフを衣装や武器に反映させる
  (火=赤〜橙, 水=青〜水色, 風=緑, 土=茶〜黄土色, 雷=黄〜金, 光=白〜金, 闇=紫〜黒)
レアリティ: {rarity}(N/R/SR/SSRの順で装飾・オーラの派手さを段階的に強くする。
  N/Rは実用的で簡素な意匠、SR/SSRは装飾が増え、光の粒子やオーラ演出を加える)
元ネタモチーフ: {STORY.mdの「元ネタ」。例: 雪女(旅人を凍らせるが、情を通わせた相手だけは
  見逃したという伝承)} → シルエットや小物、色使いにさりげなく反映させる
  (直接的なコスプレにはせず、「言われてみれば元ネタが分かる」程度の抽象度に留める)
性格: {STORY.mdの「性格」。例: クールで人と距離を置きがち、皮肉屋。だが根は情に厚い}
  → 表情・ポーズにその性格がにじむようにする
外見の方向性: {STORY.mdの「外見の方向性」。例: 白銀の着物風ローブ、雪の結晶模様、
  冷気をまとう長い黒髪}
装備デザイン: 布・革・金属などの伝統的な意匠に、属性カラーで発光する細い回路状のライン
  (刺繍のような曲線)を織り交ぜる。武器や防具の一部に、磨かれたクリスタルの
  パーツ(小さな記憶のかけらの欠片を身につけている、という設定)を配置する。
  レアリティが高いほど、その発光ラインとクリスタルパーツの密度・輝きが増す。
ポーズ: 武器を構えた、動きのある立ちポーズ。目線はやや上か正面。
画風: 美麗で可憐なソシャゲ風。線は繊細に、瞳や衣装のハイライトに交界石を思わせる
淡い発光エフェクトを加える。背景は近未来都市のシルエットをうっすら透過で
匂わせる程度に留め、主役はあくまでキャラクター本体にする。
縦横比: 3:4(縦長バストアップ〜全身が収まる比率)。
```

## 4. カードデザイン テンプレ

`src/data/cards.ts` の1枚分のデータ(カード名・種別・属性・関連キャラ)を
差し込んで使うプロンプト。カード全体のフレーム込みで生成する。
**レアリティが上がるほど、絵の情報量・光の演出・フレームの豪華さを明確に段階的に
上げること**(N→R→SR→SSRで一段ずつ格が上がって見えるようにする)。

### 4.1 レアリティ別クオリティ指針(必ずプロンプトに含める)

| レアリティ | 構図 | エフェクト | フレーム |
|---|---|---|---|
| N | 静止した簡潔な構図、被写体1つ | エフェクトはほぼ無し、最小限の光沢のみ | シンプルな線のみの縁取り |
| R | ややダイナミックな構図 | 属性カラーの淡いグロー・小さな光の粒子 | 縁取りに細い発光回路ラインを追加 |
| SR | 動きのある構図、背景に簡単なエフェクト | 属性カラーの強いグロー、飛び散る光の粒子、箔押しのような光沢 | 縁取りが二重になり装飾紋様が増える |
| SSR | フルダイナミックな構図、背景まで作り込む | 画面全体を包む光のオーラ、虹色/ホログラム的な反射、粒子エフェクトが最も豊か | 縁取りが最も装飾的、四隅に紋章、後光のような光背 |

### 4.2 プロンプト本体

```
{共通スタイルアンカー}

トレーディングカード風のイラストを1枚生成してください。カード全体のフレームも含めて描く。
カード名: {name}
カード種別: {type}(attack=攻撃/skill=スキル/power=パワー)
  → attackは攻撃的な一瞬の動作、skillは技や防御の構え、powerは持続効果を示す
    象徴的なオーラ/紋章のイラストにする
属性: {element}(属性ごとの色をカード全体の縁取り・背景エフェクトに反映)
  火=赤〜橙, 水=青〜水色, 風=緑, 土=茶〜黄土色, 雷=黄〜金, 光=白〜金, 闇=紫〜黒
  (属性なしの基本カードは無属性=銀〜白のシンプルな縁取り)
レアリティ: {rarity} → 上記「4.1 レアリティ別クオリティ指針」の表に厳密に従い、
  構図・エフェクト・フレームの豪華さを該当レアリティの水準に合わせること。
  N/Rで作りすぎない(SSRと差別化するため簡潔さを保つ)。
フレーム意匠: カードの縁取りを、彫刻的な紋様と、細い発光回路ラインを組み合わせたデザインにする。
  カード左上のコスト表示部分は、磨かれたクリスタルに数字が浮かぶホログラムのような見た目にする。
関連キャラクター: {linkedCharacterId が指定されている場合はそのキャラの必殺技・専用カードを
  イメージした演出にする。可能であればSTORY.md 6章のそのキャラの元ネタモチーフも
  カードイラストに反映する。基本カード(無所属)の場合は特定キャラを描かず、
  技そのものの象徴的なイラストにする}
構図: カード上部2/3にイラスト、下部にカード名・コスト・効果テキストを配置するレイアウト
  (実際のテキストは書かず、レイアウトの空間だけ意識してイラストを描く)。
縦横比: 5:7(トレーディングカード標準比率に近い縦長)。
```

## 5. 素材アイコン テンプレ(強化/進化/解放/記憶のかけら)

`src/data/economy.ts` の素材(MaterialType)用。ダンジョン報酬・所持数表示に使う
小さめのアイコン素材。特に「記憶のかけら」はSTORY.mdの核となるモチーフなので、
他の素材よりも一段美しく・意味深に描く。

```
{共通スタイルアンカー}

ゲーム内アイテムアイコンを1枚生成してください。背景は透過。
アイテム名: {素材名。例: 記憶のかけら}
デザイン: {記憶のかけらの場合}
  割れたクリスタルの欠片のような形。内部にごく淡く、誰かの後ろ姿や光景の断片のような
  ホログラム状の像がうっすらと浮かんで見える(具体的な顔や場面は描かず、
  光の揺らぎとして抽象的に表現する)。輪郭には細い発光回路のラインが走る。
  色は淡い虹色〜白金色のグラデーション。
  {それ以外の素材の場合: 強化素材=歯車とクリスタルの融合意匠(暖色系) /
  進化素材=繭・DNA螺旋を思わせる結晶構造(緑〜青系) / 解放素材=鍵穴とクリスタルの
  融合意匠(金系)}
縦横比: 1:1(正方形、アイコン用)。単体アイテムとして中央に配置。
```

## 6. 運用メモ

- 同じキャラ/カードで生成し直す場合は、上記プロンプトに加えて
  「前回生成した{キャラ名}と同じ配色・デザインの方向性で」を末尾に足すと再現性が上がる。
- SSRクラスは装飾過多になりがちなので、生成後に「もう少しシンプルに」と
  追加指示を出すと調整しやすい。
- 「近未来的」要素(発光回路・ホログラム紋様)が強すぎてSFになりすぎた場合は、
  「回路のラインをもっと有機的で植物のツルのような曲線にして、機械的な直線を減らして」
  と指示すると、神秘寄りに調整しやすい。
- 元ネタモチーフを反映させすぎて特定の実在キャラクター(既存作品のコスプレ)に
  寄りすぎた場合は、「元ネタが分かる程度に抽象化して、もっとオリジナルのシルエットに」
  と指示すると調整しやすい。
