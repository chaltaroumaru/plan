# スパイア・クロス ChatGPT画像生成プロンプト集

> `STORY.md` の世界観(境界が交わる場所に聳える神秘的な塔・交界石)に合わせた、
> ChatGPT(画像生成)に貼り付けて使うプロンプトのテンプレート集です。
> `{ }` で囲んだ部分を差し替えるだけで、キャラやカードが増えても同じ画風で量産できます。

## 0. 共通スタイルアンカー(全プロンプトの先頭に必ず付ける)

キャラ・カード・背景すべてに共通で入れる「世界観の軸」。これを毎回コピペすることで、
生成のたびに絵柄がブレるのを防ぐ。

```
世界観: 無数の世界の境界(バウンダリー)が交わる場所に聳える、神秘的な塔「スパイア」を舞台にした
ファンタジーRPG。めちゃくちゃきれいで幻想的、透明感のある光の演出。紺碧・深紫・金・淡い虹色の
オーロラのようなグラデーションを基調とした、美麗で可憐なアニメ/ソシャゲ風イラスト。
塔は白銀と紺碧の結晶建築で構成されており、浮遊する結晶の欠片や光の粒子が漂う。
```

## 1. ホーム背景(拠点/ホーム画面用)

すでに実装済みの背景画像(`assets/backgrounds/home_background.jpg`)と同じ路線の
バリエーション違いを作りたいとき、または将来的に章・季節ごとに差し替えたいときに使う。

```
{共通スタイルアンカー}

縦長のスマートフォン壁紙イラストを1枚生成してください。
構図: 画面中央〜上部に、天まで届く巨大な塔「スパイア」を下から見上げるように配置。
塔の周囲には浮遊する結晶の島々、光の粒子、淡いオーロラ状の光の帯が漂う。
画面下部は雲海または浮遊する島の縁を描き、UIを重ねても視認性が保てるよう
下部1/3ほどは自然に暗く沈み込むグラデーションにする。
キャラクターは配置しない(背景のみ、UIオーバーレイ前提)。
縦横比: 9:16(スマホ画面比率)。塔の構図は画面上端付近で揃うようにする。
テイスト: {季節/章の指定。例:夜明けの黄金の光 / 満天の星と紫紺の夜空 / 桜吹雪の舞う春}
```

## 2. バトルフィールド背景

バトル画面用。ホーム背景よりも横長・奥行きのある構図にし、UI(敵/味方/手札)を
重ねる前提で中央〜下部を比較的落ち着いた色味にする。

```
{共通スタイルアンカー}

バトル画面用の背景イラストを1枚生成してください。
構図: 塔の内部、または塔を巡る道中の一場面。奥に塔本体や結晶の柱、
浮遊する足場が見える構図。画面中央〜上部にはある程度の空間的な奥行きを残し、
敵キャラクターの立ち絵を重ねても違和感が出ないようにする。
画面下部1/3は、味方キャラクター・手札UIを重ねる前提で、
コントラストを落とした落ち着いた色味(暗めの紺・紫)にする。
縦横比: 9:16(スマホ画面比率)。
エリアの指定: {例: 塔の入り口付近・崩れかけた回廊 / 塔中層・結晶の大広間 / 塔上層・雲を突き抜けた尖塔}
明るさ: 主UIの視認性を優先し、全体的に彩度・明度をやや抑える。
```

## 3. キャラクターデザイン テンプレ

`src/data/characters.ts` の1体分のデータ(名前・二つ名・属性・レアリティ)を
そのまま差し込んで使うプロンプト。立ち絵(全身)とアイコン(バストアップ)の
2種類のテンプレを用意。

### 3.1 全身立ち絵

```
{共通スタイルアンカー}

キャラクターの全身立ち絵イラストを1枚生成してください。背景は透過(白背景でも可)。
キャラクター名: {name}
二つ名: {title}
属性: {element}属性 → 属性に応じた色・モチーフを衣装や武器に反映させる
  (火=赤〜橙, 水=青〜水色, 風=緑, 土=茶〜黄土色, 雷=黄〜金, 光=白〜金, 闇=紫〜黒)
レアリティ: {rarity}(N/R/SR/SSRの順で装飾・オーラの派手さを段階的に強くする。
  N/Rは実用的で簡素な意匠、SR/SSRは装飾が増え、光の粒子やオーラ演出を加える)
ポーズ: 武器を構えた、動きのある立ちポーズ。目線はやや上か正面。
画風: 美麗で可憐なソシャゲ風。線は繊細に、瞳や衣装のハイライトに交界石を思わせる
淡い発光エフェクトを加える。
縦横比: 3:4(縦長バストアップ〜全身が収まる比率)。
```

### 3.2 アイコン用バストアップ

```
{共通スタイルアンカー}

上記と同一キャラクターのアイコン用バストアップイラストを1枚生成してください。
背景は属性カラーを基調とした円形または放射状のグラデーション背景。
表情: 性格が伝わる自然な表情(例: {性格の一言。例:まっすぐで実直な笑顔})。
縦横比: 1:1(正方形、アイコン用)。
```

## 4. カードデザイン テンプレ

`src/data/cards.ts` の1枚分のデータ(カード名・種別・属性・関連キャラ)を
差し込んで使うプロンプト。カード全体のフレーム込みで生成する。

```
{共通スタイルアンカー}

トレーディングカード風のイラストを1枚生成してください。カード全体のフレームも含めて描く。
カード名: {name}
カード種別: {type}(attack=攻撃/skill=スキル/power=パワー)
  → attackは攻撃的な一瞬の動作、skillは技や防御の構え、powerは持続効果を示す
    象徴的なオーラ/紋章のイラストにする
属性: {element}(属性ごとの色をカード全体の縁取り・背景エフェクトに反映)
  火=赤〜橙, 水=青〜水色, 風=緑, 土=茶〜黄土色, 雷=黄〜金, 光=白〜金, 闇=紫〜黒
  (属性なしの基本カードは無属性=銀〜白のシンプルな縁取り)
レアリティ: {rarity}(N/R/SR/SSRでフレームの装飾密度・光のエフェクト量を段階的に増やす)
関連キャラクター: {linkedCharacterId が指定されている場合はそのキャラの必殺技・専用カードを
  イメージした演出にする。基本カード(無所属)の場合は特定キャラを描かず、
  技そのものの象徴的なイラストにする}
構図: カード上部2/3にイラスト、下部にカード名・コスト・効果テキストを配置するレイアウト
  (実際のテキストは書かず、レイアウトの空間だけ意識してイラストを描く)。
縦横比: 5:7(トレーディングカード標準比率に近い縦長)。
```

## 5. 運用メモ

- 同じキャラ/カードで生成し直す場合は、上記プロンプトに加えて
  「前回生成した{キャラ名}と同じ配色・デザインの方向性で」を末尾に足すと再現性が上がる。
- SSRクラスは装飾過多になりがちなので、生成後に「もう少しシンプルに」と
  追加指示を出すと調整しやすい。
- 生成した画像は `assets/backgrounds/`(背景)・`assets/characters/`・`assets/cards/`
  (今後追加予定)に配置し、PNG→JPEG圧縮(背景)や透過PNGのまま(キャラ/カード)で
  バンドルサイズを抑えて取り込む。
