# 恋人メモ (koibito-memo)

記念日・プレゼント・化粧品・好きなもの・生理周期を1つにまとめて管理できる、1人用のメモアプリです。React Native (Expo) + TypeScript で実装しており、データはすべて端末内 (AsyncStorage) に保存されます。ログインやサーバーは不要です。

## 機能

- **ホーム**: 次の記念日・未対応のプレゼント・要チェックの化粧品・生理予測をまとめて表示するダッシュボード。
- **記念日**: 記念日を登録し、次回までの日数を自動でカウントダウン(毎年繰り返し設定可)。
- **プレゼント**: あげる/もらうプレゼントのアイデアや記録を、ステータス(アイデア/予定/贈った/もらった)ごとに管理。
- **化粧品**: 商品ごとに開封日と使用期限(開封後◯ヶ月)を記録し、期限が近いものやリピート購入したいものを一覧化。
- **好きなもの**: 好きな食べ物・色・サイズ・苦手なものなどをカテゴリ別にメモ。
- **生理管理**: 生理開始日を記録すると、平均周期と次回の予測日を自動計算。

## 開発

```bash
npm install
npm run web    # ブラウザで起動 (react-dom / react-native-web が必要)
npm run start  # Expo Dev Tools (実機は Expo Go アプリでQRコードを読み取り)
```

型チェック: `npx tsc --noEmit`

## 主なディレクトリ

- `src/types` : 型定義
- `src/storage` : AsyncStorage 永続化とリスト操作用フック
- `src/utils/date.ts` : 日付計算(カウントダウン・周期予測など)
- `src/screens` : 各画面 (ホーム/記念日/プレゼント/化粧品/好きなもの/生理管理)
- `src/components` : 共通UIコンポーネント (フォーム・カード・モーダルなど)
